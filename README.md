# 📧 Phishing Email Analyzer

A professional phishing email analysis platform built in Python.

## Features (Planned)

- Email (.eml) parsing
- Header analysis
- SPF validation
- DKIM validation
- DMARC analysis
- Sender spoofing detection
- URL extraction
- URL reputation checks
- Attachment analysis
- Risk scoring engine
- Interactive web dashboard
- PDF analysis reports
